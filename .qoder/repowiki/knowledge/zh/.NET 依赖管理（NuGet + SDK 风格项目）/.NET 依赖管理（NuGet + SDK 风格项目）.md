本仓库采用 .NET 10 的 SDK 风格项目（Sdk="Microsoft.NET.Sdk"），通过 NuGet 管理第三方依赖，未使用包锁定文件或私有源配置。

**使用的系统与工具**
- 包管理器：NuGet（随 .NET SDK 内置）
- 项目格式：SDK 风格 csproj，直接在 `<PackageReference>` 中声明依赖与版本
- SDK 版本锁定：`global.json` 固定为 `10.0.100`，允许 `latestFeature` 前滚和预发行版
- 全局属性：`Directory.Build.props` 统一设置 Nullable、ImplicitUsings、LangVersion

**核心文件与位置**
- `Agentic.Desktop/Agentic.Desktop.csproj`：唯一的项目文件，集中声明所有 NuGet 包引用
- `global.json`：锁定 .NET SDK 版本
- `Directory.Build.props`：跨项目全局编译属性
- `.gitignore` 忽略 `*.nuget.props`、`*.nuget.targets` 等中间文件

**已引入的依赖**
- 框架与平台：`Microsoft.WindowsAppSDK` 2.3.1、`Microsoft.Windows.SDK.BuildTools` 10.0.28000.2526、`Microsoft.Windows.SDK.BuildTools.WinApp` 0.5.0
- UI 与 MVVM：`CommunityToolkit.Mvvm` 8.4.2
- 文本处理：`Markdig` 1.3.2
- 日志：`Microsoft.Extensions.Logging.Debug` 9.0.7
- 业务库：`ShihaoShen.Agentic.ACPLibrary` 0.1.0-beta.3（私有或内部 NuGet 包）

**架构与约定**
- 无 `packages.lock.json` 或 `Directory.Packages.props`，版本号直接内联在 csproj 中
- 无 `NuGet.config`，未配置私有源或代理，依赖默认从 nuget.org 恢复
- 未启用包还原缓存或离线模式，构建完全依赖网络恢复
- MSIX 打包通过 `<EnableMsixTooling>true</EnableMsixTooling>` 启用

**开发者应遵循的规则**
- 新增依赖时直接在对应项目的 `<ItemGroup>` 中添加 `<PackageReference Include="..." Version="..." />`
- 保持 `global.json` 中的 SDK 版本与团队环境一致，避免随意升级
- 如需私有源或认证，应在解决方案根目录添加 `NuGet.config` 并纳入版本控制
- 建议引入 `packages.lock.json` 以确保可重复构建（当前未启用）
- 对预发布包（如 `-beta.3`）应保持谨慎，评估稳定性后再提升为主版本
