该仓库使用 .NET 10 + WinUI 3 + Windows App SDK 构建桌面客户端，通过 MSBuild 项目文件、全局属性文件和发布配置文件组织完整的编译、打包与发布流程。

**构建系统与工具链**
- SDK 版本锁定在 `global.json` 中指定为 `10.0.100`，启用 `rollForward: latestFeature` 和 `allowPrerelease`，确保团队使用一致的 .NET 10 SDK。
- 根级 `Directory.Build.props` 统一启用 Nullable、ImplicitUsings 和最新 C# 语言版本，所有子项目自动继承这些编译器选项。
- 项目文件 `Agentic.Desktop.csproj` 基于 `Microsoft.NET.Sdk`，输出类型为 `WinExe`，目标框架为 `net10.0-windows10.0.26100.0`，最低平台版本 `10.0.17763.0`。

**多架构支持**
- 项目同时支持 x86、x64、ARM64 三种平台（`<Platforms>x86;x64;ARM64</Platforms>`）。
- 运行时标识符根据当前进程架构自动推断：`win-$([System.Runtime.InteropServices.RuntimeInformation]::ProcessArchitecture.ToString().ToLowerInvariant())`。
- 每个架构对应独立的发布配置文件（`Properties/PublishProfiles/win-{platform}.pubxml`），定义自包含发布、输出目录等参数。

**MSIX 打包与发布**
- 启用 `EnableMsixTooling` 和 `Microsoft.Windows.SDK.BuildTools.WinApp`，支持 VS 中的 "Package and Publish" 上下文菜单。
- `Package.appxmanifest` 声明应用身份、依赖、资源语言（en/zh-CN/zh-TW/ja）、能力（runFullTrust、systemAIModels）和视觉元素。
- 发布配置采用 FileSystem 协议，输出到 `bin\$(Configuration)\$(TargetFramework)\$(RuntimeIdentifier)\publish\` 目录。

**调试与运行**
- 通过 `Microsoft.Windows.SDK.BuildTools.WinApp` 实现 `dotnet run` 直接运行打包的 WinUI 应用，自动注册调试身份并通过 AUMID 启动。
- `launchSettings.json` 提供开发时的启动配置。

**构建优化**
- Debug 配置禁用 ReadyToRun 和裁剪以加快迭代速度；Release 配置启用两者以减小体积和提升启动性能。
- 使用 `PublishTrimmed` 进行程序集裁剪，减少部署包大小。

**开发者约定**
- 新增架构时需在 `Properties/PublishProfiles/` 下添加对应的 `.pubxml` 文件。
- 所有新项目应放在解决方案根目录下，自动继承 `Directory.Build.props` 中的编译器设置。
- 资源文件按语言分目录存放于 `Strings/{locale}/Resources.resw`，并在 appxmanifest 中声明。
