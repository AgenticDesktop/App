The application follows a classic WinUI 3 MVVM pattern: `App.xaml.cs` exposes static singletons (`Window`, `DispatcherQueue`, `LoggerFactory`, `CurrentAcpClient`) plus an `AcpClientChanged` event that all pages subscribe to for cross-page state. `MainWindow.xaml.cs` owns the `NavigationView`/`Frame` navigation container and dispatches between `MainPage` (chat) and `SettingsPage`. `MainPage` composes `ChatViewModel` and a child `ChatListPanel`, binding them via code-behind assignment rather than DI. Cross-cutting concerns are centralized in `Services/` (file system, localization, markdown, permissions, terminal) and consumed by ViewModels; `Converters/` provide shared XAML value converters; `Strings/` holds `.resw` resources for en/ja/zh-CN/zh-TW. The `Mocks/MockAgentTransport.cs` supports testing without a real agent. Pages communicate indirectly through the `App.CurrentAcpClient` + `AcpClientChanged` event rather than direct references.
