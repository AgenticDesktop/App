The root is a .NET solution (Agentic.Desktop.slnx) that wires two child projects: Agentic.ACPLibrary (the shared AcpClient library) and Agentic.Desktop (the WinUI 3 shell). Directory.Build.props centralizes compiler settings (nullable reference types, implicit usings, latest LangVersion) so every project inherits the same C# conventions. global.json pins the SDK to version 10.0.100 with rollForward enabled, ensuring consistent builds across developers and CI. The desktop app references the library project, forming a single-layer dependency where the UI layer consumes the shared AcpClient without additional orchestration code at this level.
